We make Nerv Linux

Nerv Dynamics AB develops and sponsors Nerv Linux, an open-source operating system for NVIDIA Grace Blackwell computers, built from scratch on musl and targeting one platform. With it come S2, an inference engine written against the CUDA driver API, axon, which makes a GPU on another machine work like a local one, and Plexus, which decides which machines may reach which. All of it is open source under Apache-2.0.

For organisations

Nerv is free to run. Organisations pay for what it takes to run a fleet under their own rules.

The management plane

One place to run a fleet of GB10 and GB300 machines: which GPUs serve which teams, which machines are enrolled and which generation each one runs. It runs on your own hardware, connected or fully air-gapped. Details →

Supported generations

A frozen, validated release of Nerv, kept patched for an agreed period and tested on your hardware and workloads, changing only through your change control. Details →

Preinstallation

Ship Nerv signed and locked down on hardware you sell. No GPL-3 package is needed to boot it, and preinstallation on GB10 and GB300 is licensed per unit. Details →

Built in Sweden, held by you

Keys are generated on each machine and never leave it, every package is built from source, and the source is open to audit. With a customer-held trust root, your key decides what your fleet runs. Licences are signed files checked offline, and nothing in Nerv calls home.
